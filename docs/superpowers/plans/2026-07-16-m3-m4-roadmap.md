## M3(W3):完整需求 + 空间网格 + 避障

**目标:** 把 BT 补成完整日常(fatigue->回家、fun->找娱乐),用空间哈希网格做邻居查询,加局部避障消除穿模,Wander 到达重选。市民有完整的"吃-睡-玩-逛"循环。

### 任务清单(到点细化)

- [ ] **T1: 扩需求与 POI** — `SimNeeds` 已含 fatigue/fun(M2 留位)。加 home 点 / fun 点到 `PoiRegistry`。`NeedsDecaySystem` 扩:fatigue 衰减、fun 衰减(各自速率);到 home 点(fatigue 反向衰减)、fun 点(fun 反向衰减)。
- [ ] **T2: 扩 BT** — `CitizenBehavior` 图补 Sequence:`Fatigued -> SetGoal(Home)`、`Bored -> SetGoal(Fun)`。加 `IsFatigued`/`IsBored` Condition。Selector 优先级:Threat(M4)>Hunger>Fatigue>Bored>Wander(M2 已有 Hunger+Wander)。
- [ ] **T3: 空间哈希网格** — `SpatialGridSystem`:把全体 SimPosition 装入固定格子哈希(格子边长 ~避障半径×2)。提供按位置查邻居的查询接口。Burst job 构建网格(grid、cellStart、cellIndex 排序后双指针)。这是规格 §5 第 3 段、§9.3 风险点。
- [ ] **T4: 局部避障** — `SteeringSystem` 增邻居排斥力:查 SpatialGrid 取半径内邻居,累加排斥方向(互斥对称)。Wander 到达(距目标 < 阈值)重选新随机点。
- [ ] **T5: 着色扩展** — `ColoringSystem` 加 Home=蓝 / Fun=黄。
- [ ] **T6: 验收** — 完整日常循环可见;无穿模(肉眼 + 录像回看);EditMode 测试覆盖网格查询正确性、避障力对称性、Wander 重选。

### 关键风险 / 决策点

- **空间网格性能(§9.3)**:5000 市民网格构建是否 < 1ms?决策点:T3 跑通后用 Profiler 测,若 grid 构建 > 2ms,改并行构建(按格子分 job)或换更粗格子。**这决定 M4 的 5000 刻度能否成立。**
- **避障参数**:排斥力强度 / 半径需调参,过强会抖动、过弱仍穿模。T4 完成后开 Play 反复调,录像确认。
- **GO 同步开销**:M2 已注 `GetComponent<CitizenAuthoring>` 每帧缓存开销。M3 在 `CitizenRegistry` 缓存 `CitizenAuthoring[]` + `Renderer[]` 数组,消掉 per-frame GetComponent。决策点:5000 时 Snapshot/Resolve 主线程回写是否 > 5ms?若是,M4 再议"降低回写频率 / 关键帧回写"。

### M3 交付物(规格 §7)

- 完整日常循环(吃-睡-玩-逛)BT 驱动
- 空间哈希网格可用,邻居避障生效,无穿模
- EditMode 测试覆盖网格/避障/重选

## M4(W4):威胁 + 刻度盘 + HUD v2 + Profiling + 交付

**目标:** 加威胁区与 ThreatDetection(enableable 标记),BT 插入 Flee,逃出威胁后恢复日常。开放 100/500/2000/5000 刻度盘。HUD v2 显示各刻度 FPS 曲线。Profiler 截图 + Burst 对比 + README + 录像。

### 任务清单(到点细化)

- [ ] **T1: 威胁区 + ThreatDetection** — 场景放威胁区(圆形 trigger 或区域定义)。`ThreatDetectionSystem`:检测市民是否在威胁区内,在则给 entity 打 enableable tag `Threatened`。规格 §5 第 4 段、§9.2(enableable)。
- [ ] **T2: BT 插入 Flee** — `CitizenBehavior` Selector 顶部插 `Threatened -> SetGoal(Flee)`(逃出威胁区方向)。`BtScheduler` 改:被 `Threatened` 标记的 agent **插队 tick**(跳过分片节流,即时反应),规格 §4 "威胁插队"。
- [ ] **T3: Flee 着色** — `ColoringSystem` 加 Flee=白。
- [ ] **T4: 刻度盘** — Inspector/运行时开关切 100/500/2000/5000 市民。`CitizenBootstrap.count` 可热调或重建。规格 §7 "scale dial"。
- [ ] **T5: HUD v2** — HUD 加 FPS 曲线(滚动折线)、各刻度帧时间标注。沿用 M1 HUD 框架(Canvas+Text,或升级 TMP)。
- [ ] **T6: Profiling + Burst 对比** — 各刻度录 Profiler 截图;对比 Burst on/off 的 SteeringSystem 耗时曲线。规格 §9 性能验收。
- [ ] **T7: 交付物** — README(架构说明 + 运行步骤 + 性能数据)+ 录像(GIF/MP4)。

### 关键风险 / 决策点

- **enableable 组件(§9.2)**:Entities 6.5 的 enableable tag 用法需确认(`[WithAll]` vs `Enabled` 位)。T1 spike 确认 ThreatDetection 标记方式。
- **5000 GO 同步上限(§9.4,最高风险)**:5000 市民 × Snapshot/Resolve 主线程回写 Transform 是否撑得住 60fps?决策点:T4 跑 5000 时若整帧 > 16ms,选项:(a) 降回写频率(每 N 帧回写一次,视觉容忍);(b) 关键帧回写(只在 BT 决策时回写);(c) 只在变化时回写。**这是整个 demo 的天花板,需在 README 里如实标注 5000 的实际帧率,不强行宣称达标。**
- **Burst 对比可信度**:对比须同场景同种子,只切 Burst 开关。T6 记录两套数据。
- **威胁插队正确性**:插队 tick 不能破坏分片 cursor 一致性。T2 测试:威胁出现后该 agent 下一帧即 tick。

### M4 交付物(规格 §7)

- 威胁区 + Flee 闭环,威胁插队即时反应
- 100/500/2000/5000 刻度可切,各刻度 Profiler 截图 + FPS 曲线
- Burst on/off 对比数据
- README + 录像,完整可交付 demo
